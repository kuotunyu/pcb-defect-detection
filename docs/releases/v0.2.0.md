# v0.2.0 — PCB 人工複核工作站

`v0.2.0` 將既有的 leakage-aware PCB defect-detection evidence 整理成一個以正體中文為主、可直接從 GitHub README 理解的人工複核工作站。

## Highlights

- 新增完整的 PCB review-workstation portfolio UI，將原圖／標註視角、關鍵 metrics、model family 與 Promotion Gate 放進同一條閱讀動線。
- 重新設計 desktop、tablet 與 mobile responsive layout，提升內文字級、行距、導覽與 CTA 可讀性，並減少無效空白與裝飾層級。
- 以 Calm precision 視覺系統統一 pine、sage、warm ivory、peach 與 high-contrast blocked state。
- 新增 skip link、semantic landmarks、keyboard focus、reduced-motion 與窄螢幕導覽行為。
- README 直接展示由實際運行頁面擷取的 1440×900 desktop 與 390×844 mobile screenshots。

## Evidence boundary

本版沒有改寫任何研究結論，也沒有為展示目的放寬 deployment gate：

- Grouped mAP50 仍為 `63.30%`，same-board exposure effect 仍為 `+21.3 pp`。
- ONNX Runtime CUDA FP32 NVIDIA L4 calibration-only p50 仍為 `20.28 ms`。
- Aggregate fidelity 通過，但 strict per-box prediction parity 仍未通過。
- Public inference 維持 unavailable；不發布 dataset media、weights、ONNX exports 或 TensorRT engines。
- 工作站中的 PCB 畫面是明確標示的 synthetic illustration，不是模型 prediction。

## Verification

Release publication requires a clean `main` tree, locked non-editable install, Ruff lint and format checks, the complete pytest suite, wheel/sdist build, deterministic research-package verification, and a successful GitHub Actions run at the tagged commit.

The immutable `v0.1.0` tag, research-package hash, and Zenodo DOI remain unchanged. The `v0.2.0` Zenodo version DOI is recorded only after the new record has been published.

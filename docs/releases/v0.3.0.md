# v0.3.0 — 六板複驗與 parity 根因

`v0.3.0` 把單一 Board 08 的 same-board exposure 結果擴成預登記的六板 leave-one-board-out 複驗，並補上 strict per-box parity 失敗的根因診斷、runner 修正與修正後的 NVIDIA L4 重跑證據。

## Highlights

- 新增 leave-one-board-out 複驗：資格規則允許的六塊板（05、07、08、09、11、12）各當一次 held-out board，沿用同一套凍結 protocol、recipe、seeds 與 evaluator。分析方法在跑之前登記在 `docs/lobo-preregistration.md`，`reports/lobo/summary.json` 記錄該文件的 SHA-256。
- 六塊板的 leaky − grouped mAP50 全部為正：平均 `+12.8 pp`，範圍 `+1.8` 到 `+21.3`，以板為單位重抽樣 10,000 次的 95% 區間 `+6.5` 到 `+18.3 pp`。每塊板的公開 metadata 在 `reports/lobo/boardNN/`。
- 新增 `pcb_defect.lobo`（fold 註冊表、result package 匯入、預登記聚合、Colab handoff）與 protocol 路徑參數；預設路徑與既有結果不變。
- 找出 strict per-box parity 失敗的根因：Ultralytics `predict()` 預設 `rect=True`，讓 PyTorch reference 走 `352×640` 矩形 letterbox，而 exports 固定 `640×640`。`benchmark.py` 以 `ULTRALYTICS_INPUT_CONTRACT` 固定 reference 輸入；門檻、evaluator 與 parity config 不變。
- 修正後 L4 重跑：ONNX Runtime CUDA FP32 在 60/60 calibration images 逐框對上 PyTorch；TensorRT FP16 差 1/60，gate 依原規則仍記 failed。第一次的 failed evidence 原封保留在 `reports/backend_parity_l4.json`。
- README 新增 Manim 解說動畫與 Mermaid 流程圖；動畫中的數字由測試綁定到 committed evidence。

## Evidence boundary

- Board 08 的 grouped mAP50 仍為 `63.30%`，same-board exposure effect 仍為 `+21.3 pp`；Board 08 沒有重跑。
- 六板複驗只涵蓋資料集允許 held out 的 60 張板；01、04、06、10 從未 held out，n = 6 的板級區間只是近似，每個 fold 仍是單一板 30 張 final test。
- Aggregate fidelity 通過，strict per-box prediction parity 兩次都未通過；沒有調整任何門檻。
- Public inference 維持 unavailable；不發布 dataset media、weights、ONNX exports 或 TensorRT engines。
